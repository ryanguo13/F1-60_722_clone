# F1-60 722 clone — 设计规划

目标不是「能打印的矩形托盘」，而是视频
[F1-60 722 HHKB FINAL PROTOTYPE](https://www.youtube.com/watch?v=NqCcKtChTF0)
和 [LAUNCHER60](https://geon.works/products/launcher60-keyboard-case) 的外壳外形。
配列改成 **60% WKL ANSI**（不要 HHKB / true HHKB）。不做 Geon 铭牌。

本文件取代上一版「先打矩形托盘、楔形以后再说」的规划。楔形切割已在 Fusion 2706 上验证。

---

## 1. 目标外形（视频 / Launcher 60 / F2-60）

Launcher 60 是 F1-8X 722 家族的 60% 聚碳酸酯壳：楔形、前后 36° 倒角、R3 圆角、后沿横条、后置 USB-C、底面配重格。F2-60 RENDER STEP 是同系列 60% 几何，XY 已量准，角度是 9°（OG 系）。本复刻把角度改成 **7.22°**，宽度对齐 F2-60，深度因热熔垫加长。

| 量 | 来源 | 采用 |
| --- | --- | --- |
| 外壳 XY | F2-60 TOP 宽 299.20；深因前后热熔垫加长 | **299.20 × 129.20 mm** |
| 打字角 | 产品名 722；F2-60 STEP 实测 9° | **7.22°** |
| 前端高度 | F1-8X 722 图纸 FRONT HEIGHT | **16.0 mm**（桌面 → 打字面，前唇） |
| 后端高度 | `16 + 129.20 × tan(7.22°)` | **32.37 mm** |
| 平面圆角 | F2-60 TOP 柱面 R3，轴沿打字面法向 | **R3.0** |
| 前后倒角 | F2-60 顶面前后棱，法向 36° / 54° | 顶面前后棱 **~1.2 mm × 36°** |
| 上盖沿 Z 厚 | 保证底壳前缘 ≥ 8 mm 放热熔螺母 | **8.0 mm**（平行于打字面切开） |
| 壁厚 | 嘉立创 FDM + X4 经验 | **3.0 mm** |
| 后横条 | Launcher 60 实拍；F1-8X 722 条配重 | **3.0 × 8.0 × (W − 3)**，无 logo |
| USB | F2-60 ai03 UDB-C，壳宽中心、后壁 | 18 × 8 圆角槽，子板 18 × 16.5 |
| 底脚 | F2-60 两条 7 × 1.5 mm 胶脚 | 底壳底面两条凹槽 |
| 配重 | F2-60 两块铜配重 | 底壳预留一个大槽，后加不锈钢 |
| 螺钉 | 前唇 2 + 后沿 2（不进侧壁） | **4 × M3**，嘉立创 `M3*4*3` |

不抄 F1-8X 的 6 颗 M2.5 上下对拧、也不做铜配重和铭牌。3D 打印用热熔螺母更稳。

## 2. 坐标系

```
x: 0 → 299.20     左 → 右
y: 0 → 129.20     前唇 → 后沿
z: 0 = 桌面，+z 向上

打字面:  z(y) = 16.0 + y × tan(7.22°)
分型面:  z(y) =  8.0 + y × tan(7.22°)     （上盖 8 mm 厚，沿 Z）
```

草图在 XY，拉伸到 `rear_h`，再用 **YZ 梯形切除**打出楔形。
已验证：YZ 草图 X → 世界 −Z，Y → 世界 Y；切除 `z > z_typing(y)` 的那一块即可。

## 3. 零件分工

```
TOP     上盖：完整外形 299.20 × 129.20，楔形，R3
        侧壁 3 mm，前后壁 16 mm，顶面键帽窗口，后壁 USB 槽，后沿横条凹台
        前唇 / 后沿各两颗 M3 通孔 Ø3.4
BOTTOM  底壳：同外形（打印对位），分型面以下
        内腔 + 14×14 热熔垫（前 2 / 后 2）+ Ø3.6×5.0 盲孔（从底面嵌）
        2.0 mm 底板 + 两条脚垫槽 + 后壁 USB 槽
PLATE   定位板 285.75 × 96.10 × 1.5，R2.4
        WKL ANSI 开孔；只在左右内边有支承（F1-8X 桨式：前后留空）
BAR     后横条，摩擦进上盖凹台，无铭牌
PCB     用户已有 ai03 子板 60%；用 waffling60-DB STEP 做间隙检查
```

上盖 / 底壳分型平行于打字面。上盖朝下开口扣到底壳上，四颗 M3 从下往上拧进上盖？
否：沿用 X4 / 上一版——**螺母在底壳，螺钉从底壳底面拧入、穿过分型进上盖的通孔**。
打印时底壳开口朝上、底面贴床，热熔孔朝下由嘉立创代嵌。

> 若底壳前缘 8 mm 里 5 mm 是螺母孔，剩余 3 mm 底板，可接受。垫块做 14×14，孔周壁 (14−3.6)/2 = 5.2 ≥ 3.0。

## 4. 定位板（WKL，F1-8X 桨式支承）

公开定位板没有。F2-60 STEP 的板在打字面内是 **285.70 × 96.10** 圆角矩形（凸包 16 点，角部约 R2.4）。键区正好 15u × 5u。

本复刻：

- 外廓 **285.75 × 96.10 × 1.5**，R2.4，在壳内左右各留 ~6.7 mm、前后各留 ~16.55 mm（16 mm 壁吃掉热熔垫）
- 键位：标准 60% WKL ANSI（与 WK 同孔；Win 位打 blocker）
  - R0 13×1u + 2u
  - R1 1.5 + 12×1 + 1.5
  - R2 1.75 + 11×1 + 2.25 Enter
  - R3 2.25 Shift + 10×1 + 1.75 + 1u
  - R4 1.25×3 + 6.25 + 1.25×4
- 开孔：14×14 轴孔（本机 Fusion 圆切会过切，继续用方孔）
- 卫星轴：L-Shift 2.25 / Enter 2.25 / 空格 6.25，Cherry PCB-mount 槽 6.75×14
- **桨式**：壳内只在左右做 1.5 mm 托台，前后内壁与板留 ≥ 2 mm 空隙，兼容 waffling60 板边缘和卫星轴

键心 Y（壳坐标系，板前缘 y = 16.55）：

```
ROW_Y = 26.71, 45.76, 64.81, 83.86, 102.91     # 板内边距 0.425 + 0.5u，行距 19.05
KX0   = 6.725                                  # (299.20 − 285.75) / 2
```

## 5. PCB 与子板

- 板：waffling60-DB / 任意 GH60 类 60%，ai03 Unified Daughterboard C
- UDB-C：18 × 16.5 mm，M2 孔 14 × 12.5；USB-C 居中朝后
- 壳后壁开槽对 UDB，**不**抄 Geon 原厂子板孔
- 验证文件：`ref/waffling60/waffling60-DB.step`、`ref/udb_c3.step`

## 6. 五金（嘉立创 FDM）

从 X4 已打过的方案照搬：

| 项 | 值 |
| --- | --- |
| 螺母 | 嘉立创代嵌 `M3*4*3`（Ø4 × L3） |
| 打印底孔 | Ø3.6 × 5.0 盲孔，从底壳**底面**开口 |
| 垫块 | 14 × 14，孔周壁 5.2 mm |
| 螺钉 | M3×8～10 盘头，上盖 / 底壳通孔 Ø3.4 |
| 脚垫 | 7 × 1.5 × ~284 / 290，胶贴，底壳凹 0.8 mm |
| 横条 | 单独打印，凹台单边 +0.2 间隙 |

四颗螺钉在**前唇 / 后沿**各两颗（`screw_x = 50`，`screw_y = 8`），不进左右侧壁。
14×14 热熔垫必须完全让开定位板，所以前后壁做成 **16 mm**，外壳 Y 从 F2-60 的 117.08 加到 **129.20**。侧壁维持 3 mm。这是打印热熔方案相对铝合金原壳的取舍：前后更宽，侧面仍接近 F1-8X 722 的 4.2 mm 边框。

## 7. 打印约束

- 外壳 299.20 mm 长，超过部分消费级 256 mm 机。嘉立创 FDM 下单时选 **≥ 300 mm** 平台（工业 FDM / 大机）。
- 壁 3.0 mm ≥ 6 圈 0.4 喷嘴；最小筋 ≥ 1.2 mm（X4 被退回的前车之鉴）
- 上盖倒扣（窗口朝上）或开口朝上均可；底壳**开口朝上、底面贴床**，热熔孔朝下
- 定位板平放；横条 3 mm 面贴床
- 材料：PLA+ / PETG；0.2 mm 层高；外墙慢打

## 8. Fusion 实现（已验证的路径）

上一版矩形托盘停在「斜切布尔不稳定」。2026-10-29 探针：

1. XY 圆角矩形拉伸到 `rear_h` — 体积与解析值一致（299.2×117.08×30.83）
2. 垂直棱 R3 倒圆 — 成功
3. **YZ 梯形切掉打字面以上** — 前缘顶点 z=16、后缘 z=30.83，成功
4. 内轮廓同样做楔再 Combine-Cut — 80×50 探针得到封闭壳体，成功
5. 构造点 / `setByThreePoints` 在本环境报 `Environment is not supported`，不用

因此：**不要**用斜构造面；**要用** YZ 侧视梯形。圆孔继续用方孔代替（本机构造圆会过切）。

脚本入口：

| 文件 | 作用 |
| --- | --- |
| `src/f1_60_722.py` | 布局与参数（WKL、板、螺钉、UDB） |
| `src/fusion_lib.py` | XY/YZ 草图、楔形切、Combine-Cut |
| `src/build_top.py` | 上盖 |
| `src/build_bottom.py` | 底壳 |
| `src/build_plate.py` | 定位板 |
| `src/build_bar.py` | 横条 |

每步打印体积 / bbox，和解析值比。导出 `out/*.step` + `out/*.stl`。
